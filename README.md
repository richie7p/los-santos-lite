# 索拉港街頭 · Port Solara Streets

**繁體中文** | [English](README.en.md)

在瀏覽器裡遊玩的 3D 開放世界犯罪動作沙盒。開車、槍戰、甩掉警方的追捕，從街頭小子一路幹到索拉港的傳奇。

免安裝、免登入、不需要任何外部素材——所有模型、貼圖、音效與電台音樂都由程式即時生成。

## 遊戲特色

### 畫面
- **日夜循環與天氣**：物理天空、太陽／月亮光影與即時陰影，夜晚有星空、亮起的窗戶、路燈與霓虹看板；隨機下雨時路面變濕反光、天空轉陰，暴雨還會打雷閃電（雨天路滑，車子抓地力變差）。
- **各區細節**：市區大樓一樓有店面招牌與遮雨棚（夜間亮燈）、公車站、消防栓、垃圾桶、花台與人孔蓋；住宅區有樹籬、信箱與後院泳池；工業區有冒煙的煙囪、儲油槽與棧板；碼頭有貨運鐵路與列車、照明塔、堆高機與拖船；海灘有救生員瞭望台、排球網、躺椅與小吃攤；山區與湖畔有針葉林、岩石、露營地營火與瞭望塔；沙漠有紅岩台地、拖車營地、抽水風車與電線桿；塵水鎮有木棧人行道、門廊、教堂與霓虹汽車旅館招牌；機場有圍籬、空橋、行李車、油罐車、風向袋與旋轉雷達；公路沿線有高壓電塔與護欄，西郊還有農田與穀倉。
- **窗戶後的房間**：每一扇窗都是有景深的室內空間（視差內部映射）——辦公室、住家與店面各有牆面、地板、天花板、家具、百葉窗與窗簾，隨視角產生真實的透視；夜晚每間房各自亮燈，偶爾看得到電視的藍光閃爍。一樓店面分成便利商店、咖啡廳與服飾店。
- **夜景**：店面燈光灑落人行道、路燈在地面形成光暈、車頭燈照亮前方路面，夜空有星星與月亮。
- **後製特效**：泛光（Bloom）、ACES 色調映射、調色、暗角、SMAA 抗鋸齒、GTAO 環境光遮蔽（高畫質）；受傷與子彈時間時有色差與去飽和效果。
- **天空與水面**：會飄動的雲層（日落染色、雨天轉厚）、太陽鏡頭光暈；海水與湖水依深度呈現淺綠到深藍，岸邊有浪花。
- **材質細節**：大樓立面有窗戶凹陷的法線貼圖；鏡頭附近的草地長出會隨風擺動的草叢；車輛有車牌、門縫與輪框輻條，人物有雕塑感的身形（男女體型、高矮胖瘦）、五官、手指、鞋底，以及夾克、短袖、短褲、裙子、帽子、墨鏡、手錶、背包、項鍊、鬍子等穿著變化；大樓有樓層簷線、厚簷口、立體陽台、屋頂機房、衛星天線與夜間頂部燈帶，住宅有煙囪、門廊、車庫門與太陽能板，市中心有行道樹。
- **約 4 × 4 公里的島嶼**：8×8 街區的索拉港市區（市中心、住宅區、工業區、海濱商圈、碼頭、海灘），外圍有北嶺山脈（山頂積雪與轉播塔）、鏡湖林區、西部沙漠與塵水鎮、西南方的索拉國際機場，並由環島快速道路串連；大樓有程序繪製的立面貼圖與夜間燈光。
- **車輛與角色**：以擠出輪廓建模、具清漆反射的車身，透過車窗看得到司機與乘客；可動作的人物骨架（走、跑、瞄準、倒地）。
- **可駕駛直升機**：機場與醫院停機坪都有直升機，空白鍵上升、Shift 下降，可以降落在屋頂上。
- **機車**：雷鳥 R6 機車加速快、過彎會壓車傾斜，看得到騎士；高速撞擊會把騎士甩飛出去。市區、海灘、小鎮與鏡湖都停有機車，路上也有機車車流。
- **粒子特效**：槍口火光、曳光彈、彈孔、火花、血霧、爆炸火球、煙霧、輪胎煙與煞車痕。

### 手感
- 越肩第三人稱鏡頭，右鍵瞄準縮放，狙擊鏡第一人稱。
- 後座力、準星擴散、擊中與擊殺標記、鏡頭震動。
- 街機式駕駛物理：重量感、側滑甩尾（手煞車）、車身側傾、跳台飛躍、碰撞損傷、起火爆炸。
- 車上可持手槍或衝鋒槍射擊；按 `Q` 啟動腎上腺素子彈時間。
- 中槍的人物會有受擊反應動作。
- **支援遊戲手把**（Xbox／PlayStation 標準配置）：左搖桿移動、右搖桿視角，RT 射擊／油門、LT 瞄準／煞車，A 跳躍、B 互動、X 換彈、Y 上下車，LB／RB 切換武器，View 地圖、Menu 暫停。
- **電腦與手機皆可遊玩**：手機會依 GPU 等級自動選擇畫質並維持清晰解析度，卡頓時自動降低解析度與畫質；選單會配合橫向小螢幕縮排，提示文字會顯示觸控按鈕名稱（例如「點 [上車]」），地圖支援雙指縮放。
- **支援手機與平板**：左半邊浮動搖桿移動、右半邊拖曳轉視角，右下角有射擊、瞄準、跳躍、上下車等按鈕（建議橫向持握）。

### 內容
- **9 章主線劇情**：重返索拉港、討債、偷車、港口伏擊、運鈔車、銀行大劫案，接著深入外圍地區──塵水沙漠的軍火交易、機場搶直升機飛往鏡湖，最後在北嶺公路追擊幕後黑手「白蟒」。
- **1–5 級通緝系統**：巡邏警車追撞、警員下車圍捕、特警廂型車、警用直升機（附探照燈，可擊落）；脫離視線並離開搜索範圍即可甩掉。1–2 星時若手無武器，警員會上前逮捕你（被捕會在警察局重生，並扣罰款與一半彈藥）；拿著武器或剛開過槍則會直接開火。
- **支線活動**：5 條賽道（含環島公路大賽與機場跑道直線加速賽，金／銀／銅牌）、快鴿速遞外送工作、9 座特技跳台、30 卷隱藏錄音帶、搶劫便利店、隨機出現的運鈔車。
- **商店**：鐵砧槍械行（8 種武器、彈藥、防彈背心）、老韓修車廠（維修、烤漆可清除通緝）、安全屋（存檔、休息）。
- **城市生態**：會過馬路的行人、站在路邊聊天的路人、邊走邊講手機的上班族，依車道行駛並會閃避的車流（公路上車速更快）與路邊停車，會被槍聲嚇跑的市民；小鎮、機場、海灘與湖畔也有遊客。遠處的行人與車輛自動切換成精簡模型，讓街道更熱鬧也不拖慢效能。
- **電影感呈現**：標題畫面在黃金時刻輪播市區、林蔭大道、海灘摩天輪、貨櫃碼頭與山丘遠眺等運鏡；任務開場有黑邊電影畫幅，完成時顯示獎金、用時與主線進度。
- **介面**：會隨鏡頭旋轉的雷達（含全島 GPS 導航）、可縮放拖曳並點擊設定導航點的全島地圖、武器輪盤、進度統計、存檔（自由行動時每 2 分鐘自動存檔）。
- **音效**：全程 Web Audio 即時合成的槍聲、引擎、警笛、環境音，以及兩個車內電台。

## 操作說明

| 按鍵 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動／駕駛 |
| 滑鼠 | 視角 |
| 左鍵 / 右鍵 | 射擊／瞄準 |
| `Shift` | 衝刺 |
| `空白鍵` | 跳躍／手煞車甩尾／直升機上升 |
| `Shift` / `Ctrl`（直升機） | 下降 |
| `F` | 上車、下車、劫車 |
| `E` | 互動（商店、任務、賽車、外送） |
| `R` | 換彈 |
| `Tab`（按住） | 武器輪盤（慢動作） |
| `1`–`8`／滾輪 | 切換武器 |
| `Q` | 腎上腺素子彈時間 |
| `M` | 地圖（點擊設定導航點） |
| `V` | 切換鏡頭距離 |
| `H` | 喇叭／警車警笛 |
| `B` | 切換電台 |
| `Esc` | 暫停、設定 |

> 小技巧：到老韓修車廠烤漆可以清除 3 星以下的通緝；被追捕時先躲出警方視線，再離開雷達上的藍色搜索圈。

## 快速開始

```bash
git clone https://github.com/richie7p/los-santos-lite.git
cd los-santos-lite
npm install
npm run dev
```

用瀏覽器開啟 <http://localhost:8080>。建議使用桌上型電腦的 Chrome／Edge／Firefox，搭配滑鼠與鍵盤。若畫面不順，可在暫停選單把畫質調為「中」或「低」。

```bash
npm test           # 執行自動化測試（碰撞、地圖配置、車輛與人物物理）
npm run build      # 型別檢查、測試並打包到 dist/
npm run preview    # 預覽打包結果
```

推送到 `main` 分支時，GitHub Actions 會自動部署到 GitHub Pages。

## 專案結構

```
src/
├── App.tsx                 # 掛載遊戲與介面
├── ui/                     # React 介面：HUD、選單、地圖、商店
└── game/
    ├── Game.ts             # 主迴圈、玩家操控、鏡頭、商店、存檔
    ├── data.ts             # 武器與車輛數值
    ├── content.ts          # 地點、賽道、收集品
    ├── state.ts            # 介面狀態（zustand）
    ├── core/               # 數學、輸入、碰撞與射線檢測
    ├── world/              # 地圖配置、程序貼圖、城市建構
    ├── render/             # 天空與日夜、後製、粒子特效
    ├── entities/           # 角色骨架、人物、車輛模型與物理
    └── systems/            # 戰鬥、車流、行人 AI、警察、任務、雷達、音效
```
